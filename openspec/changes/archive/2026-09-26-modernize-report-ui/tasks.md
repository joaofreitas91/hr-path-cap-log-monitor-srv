# Tasks

Manual verification runs `npm run watch-log.monitor.report` and logs in as `alice@dummy.com` / `1234` (report-viewer), unless a task says otherwise. Data comes from the requests in `srv/http/` (users → groups → user-groups → integrations → fields → integration-groups → logs); at least one integration with filterable fields, logs in all four statuses, one log with an array payload and one with a non-JSON payload are needed from task 1.1 on.
